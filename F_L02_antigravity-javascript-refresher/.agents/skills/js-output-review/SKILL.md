# JavaScript Output Review

Use this skill when a student wants to verify a JavaScript refresher exercise.

Follow these steps:

1. Identify the target JavaScript file.
2. Inspect the file before running it.
3. Identify the important console.log statements.
4. Ask the student what they expect the program to print.
5. Run the file using Node.js.
6. Record the actual output.
7. Compare the expected and actual results.
8. If there is an error, explain the cause before suggesting a fix.
9. Do not modify the exercise automatically.
10. Give a short beginner-friendly explanation of the result.
