# javascript-refresher-reflection

## 00_script_in_html.html

I learned that it is possible to put JavaScript directly in the HTML using the <script> tag or to load from the other file. I also understand why the placement of the script is important.

## 01_base_syntax.js

Na-recall sakin yung mga basic syntax ng JavaScript, like kung paano ulit i-print yung output gamit lang yung console.log(). And naalala ko rin ulit na case sensitive nga pala yung JS kaya there's a difference  between myName and myname.

## 02_variables.js

Na-recall ulit sakin yung basic data types like string, number, at Boolean. I learned how to use the typeof. And mas na-gets ko rin yung difference 
ng == at === kapag nagko-compare ng values.

## 03_functions.js

I learned how to make a reusable functions using the regular and arrow function syntax. Nakita ko rin na pwede palang mag-return ang isang function ng object na maraming result.

## 04_objects.js

Na-recall ulit sakin yung paggamit ng object para i-combine yung related data and functions. Mas na-gets ko rin yung paggamit ng this to access the properties of the object.

## 05_arrays.js

I learned how to manage data sa arrays using push(), shift(), and for...of. Medyo na-practice ko rin yung map() para gumawa ng new array mula sa existing values.

## 06_control_structures.js

Na-recall lang ulit sakin yung paggawa ng decisions using if, else if, and else. Also yung for at while loops para paulit-ulit na mapatakbo ang code.

## 07_dom.html

I learned how JavaScript interacts with HTML uding DOM. Na-practice ko rin yung addEventListener(), prompt(), and setTimeout() para gumawa ng interactive webpage. Natuwa po akong gawin itong part 7 dahil na-amaze ako sa pag-change ng background color hehe.

## 08_essential_features.js

Na-apply rito yung map() na ginawa sa part 5 kaya medyo napa-practice ko na. Also, I learned how to use destructuring and spread operator sa mas modern na JavaScript. Nakita ko kung paano nakaka-help ang mga 
ito para mas simple and organized yung code.

## 09_tricky_parts.js

Medyo naguluhan ako sa part na 'to (tricky nga siya) but I learned the difference between regular and arrow functions pagdating sa this, and yung  difference ng reference copy at spread copy.

## 10_let_const.js

Na-recall ulit sakin yung difference ng let, const, at var. Mas na-gets ko rin kung kailan puwedeng i-reassign ang variable at kung bakit mas ginagamit ang let at const sa modern JavaScript.

## 11_arrow_functions.js

I learned how to make arrow fuction to traditional functions. And nakita ko rin kung paano nakakapagpaiksi ng code yung implicit return.

## 12_destructuring.js

I learned how to get values from objects and arrays using destructuring. Medyo na-practice ko rin yung destructuring directly sa function parameters.

## 13_spread_rest.js

I learned that spread is use to copy or combine arrays and objects, while rest is use to collect multiple arguments. Mas na-gets ko rin kung paano gamitin ang reduce() kasama ng rest parameters.

## 14_classes_inheritance.js

I learned how to make classes that serves as template for the objects.Na-practice ko rin yung inheritance gamit ang extends para ma-reuse ang methods ng parent class.

## 15_modules_export.js

I learned how to share code between files gamit lang ang export. Mas na-gets ko rin ang difference ng default export at named export.

## 16_modules_import.js

Na-recall ulit sakin kung paano kumuha ng exported values mula sa ibang JavaScript file gamit ang import. And mas naging clear din sa akin kung kalian gumagamit ng curly braces para sa named exports.

## 17_logical_operators.js

I learned truthy and falsy values and how &&, ||, at ! works. Medyo na-practice ko rin kung pano ginagamit ang logical operators para gumawa ng conditions tulad ng login checks.

## 18_ternary_nullish.js

I learned how to use the ternary operator as the shorter version of simple if...else. Na-practice ko rin ang optional chaining?. and yung nullish coalescing ?? para mas safe mag-access ng values and magbigay ng fallback.

## 19_strings_numbers.js

I learned the different types of methods para mag-process ng strings like yung trim(), split(), includes(), at slice(). Medyo na-practice ko rin yung parseInt(), toFixed(), at pag-check ng NaN para sa numbers.

## 20_array_methods.js

I learned the useful array methods like filter(), find(),some(), every(), at sort(). And nakita ko rin kung pano nakaka-help yung mga ito sa pag-filter, paghahanap, pag-check, and pag-organize ng data.

## 21_errors_json.js

I learned how to handle ng errors gamit lang ang try, catch, and throw para hindi basta mag-crash yung program. Medyo na-practice ko rin ang JSON.stringify() at JSON.parse() para mag-convert between JavaScript objects at JSON text.

## 22_async_javascript.js

I learned the difference of callbacks, Promises, and async/await for the tasks na hindi agad natatapos. Mas na-gets ko rin kung pano ginagawang mas readable ng async/await yung promise-based code.

## 23_closures_scope.js

Na-recall ulit sakin yung let at const, which are block-scoped kaya hindi sila basta accessible outside ng block. Mas na-gets ko rin ang closures at kung pano nakakapag-keep ng sariling count ang bawat counter.
